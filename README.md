# 商品库存管理后台系统
> SpringBoot + Mybatis‑Plus + JWT + Cookie鉴权，实现进货、出货、缺货校验、分页查询的库存后台

## 🛠 技术栈
- SpringBoot
- MyBatis‑Plus
- JWT + Cookie 登录鉴权
- MySQL
- Maven
- Lombok

## 📦 功能清单
✅ 用户登录，JWT令牌存Cookie，拦截器鉴权保护接口
✅ 商品基础信息管理
✅ 进货入库：增加商品库存
✅ 出货出库：扣减库存，**出货前校验库存，缺货阻止出库**
✅ 缺货检测逻辑，识别库存不足商品
✅ 全部列表支持分页查询（Mybatis‑Plus分页插件）
✅ 出入库操作记录留存

## 🚀 快速运行
1. 克隆项目
```bash
git clone 你的github仓库地址
```
2. 修改配置文件 `application.yml`，配置本地 MySQL 数据库地址、账号、密码
3. 执行项目 SQL 脚本，完成数据库与数据表初始化
4. Maven 刷新依赖，运行 SpringBoot 启动类
5. 项目默认访问地址：`http://localhost:8080`

## 🔐 鉴权演示流程

1. 请求登录接口，账号密码校验通过，后端生成 JWT 令牌，封装到 Cookie 返回客户端
2. 访问商品、库存等业务接口，请求自动携带 Cookie
3. 自定义拦截器读取 Cookie 内的 JWT 令牌，完成合法性、过期校验
4. Token 过期、伪造、缺失时，返回未登录提示，拒绝访问业务接口

## 📊 核心业务演示

### 进货入库

传入商品 ID、进货数量

- 业务逻辑：商品库存 += 进货数量，新增入库记录

### 出货出库

传入商品 ID、出货数量

1. 查询商品当前库存，执行缺货校验
2. 若 `当前库存 < 出货数量` → 返回提示：`库存不足，无法出货`
3. 库存充足 → 扣减对应库存，新增出货记录

### 分页查询

传入参数 `pageNum`（页码）、`pageSize`（每页条数）

- 返回分页封装数据：总条数、总页数、当前页数据集

### 缺货查询

筛选库存低于设定阈值的商品，获取缺货商品列表


## 💡 项目亮点

1. 将 JWT 存放于 Cookie，简化前端处理，后端拦截器统一鉴权
2. 出货业务自带缺货校验，完成「进货‑出货‑缺货检测」完整库存业务闭环
3. MyBatis‑Plus 分页插件，统一标准化分页返回结果
4. 完整的出入库操作记录，业务可追溯
